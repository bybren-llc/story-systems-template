# Architecture Decision Records

Short, dated records of significant harness decisions — the *why* behind a design, captured so
future work (and future contributors) don't have to reverse-engineer it.

| ADR | Title | Status |
|-----|-------|--------|
| [0001](0001-multi-model-writers-room.md) | Multi-Model / Multi-Provider Writer's Room | Accepted |

## Conventions

- One file per decision: `NNNN-kebab-title.md`, numbered in order.
- Keep the standard sections: Context → Decision → Consequences (plus Alternatives when useful).
- ADRs are immutable once Accepted; supersede with a new ADR rather than rewriting history.
