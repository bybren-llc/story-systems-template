# Sweep Notes (regenerated artifacts)

This folder holds the consolidated output of the per-scene sweep commands:

| File | Written by | Contents |
|------|------------|----------|
| `continuity-sweep-notes.md` | `/continuity-sweep` | Per-scene continuity findings, grouped by kind, ordered by severity. |
| `rewrite-sweep-notes.md` | `/rewrite-sweep` | Per-scene A–F grades + fixes, sorted weakest-first. |

**These files are overwritten on every run** — they are generated reports, not source. Each
carries a `verified_against: <commit>` stamp so you can tell whether a sweep still reflects the
current draft. Treat them as advisory: a sweep reports and proposes; you decide what to change.
